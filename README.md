# SQL Sales Analysis Project
## Overview

This project analyzes customer sales data using SQL queries.

The goal is to demonstrate fundamental SQL concepts including:

- Filtering
- Aggregation
- GROUP BY
- ORDER BY
- Business insights generation
## Dataset

The dataset contains:
- Customer Names
- Products Purchased
- Sales Amount
- Cities
## SQL Skills Demonstrated
- SELECT
- SUM()
- GROUP BY
- ORDER BY
## Key Business Questions
1. Which customer generated the highest revenue?
2. Which city produced the most sales?
3. Which product generated the highest revenue?
